# DevConnect

A full-stack developer discussion forum built using React, FastAPI, and PostgreSQL.

## Features

- User Authentication (JWT)
- Ask Questions
- Post Answers
- Upvote Questions
- Accept Answers
- Notification System
- Question View Tracking
- User Profiles

## Tech Stack

### Frontend
- React
- Vite
- Axios
- React Router

### Backend
- FastAPI
- SQLAlchemy
- JWT Authentication

### Database
- PostgreSQL

## Project Structure

DevConnect/
├── backend/
├── frontend/
└── README.md

## Run Backend

cd backend

source venv/bin/activate

uvicorn main:app --reload

## Run Frontend

cd frontend

npm install

npm run dev
